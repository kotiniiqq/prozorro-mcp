# prozorro-mcp: покрокова інструкція

Цей інструмент тримає на вашому комп'ютері копію відкритих даних Prozorro для потрібних областей. Далі ви
можете питати про тендери ШІ-асистента (Claude, Cursor та інші) звичайними словами або користуватися
командами без ШІ: шукати відкриті тендери, бачити заплановані закупівлі, аналізувати ринок і конкурентів.

Усі цифри рахує програма з офіційних даних, асистент лише пише текст. Ключі й реєстрація не потрібні.

## Крок 1. Встановіть uv

uv — це безкоштовний інструмент, який сам завантажує все потрібне для програми.

**Windows**: відкрийте «PowerShell» (Пуск → введіть PowerShell) і вставте:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**macOS**: відкрийте «Термінал» і вставте:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Закрийте вікно й відкрийте нове. Перевірте, що все встановилося:

```bash
uv --version
```

Має з'явитися щось на кшталт `uv 0.9.x`.

## Крок 2. Встановіть prozorro-mcp

```bash
uv tool install git+https://github.com/kotiniiqq/prozorro-mcp
```

Тепер у терміналі працює команда `prozorro-mcp`. Перевірте її на вбудованих демо-даних (Львівська
область, один тиждень):

```bash
prozorro-mcp search --demo --limit 5
```

Ви побачите таблицю тендерів із сумами, дедлайнами й посиланнями на prozorro.gov.ua.

Оновлення до нової версії: `uv tool upgrade prozorro-mcp`.

## Крок 3. Завантажте дані своєї області

```bash
prozorro-mcp sync --region Львівська --days 7
```

- Область можна писати як завгодно: `Львів`, `львовская`, `Lviv`, `Київ` (місто), `Київська` (область).
  Кілька областей: `--region Львівська --region Волинська`.
- Перше завантаження великої області займає приблизно 15–20 хвилин на тиждень даних. Програма ввічливо
  працює з державним сервером і не перевантажує його.
- Можна перервати (Ctrl+C) і запустити ту саму команду знову: вона продовжить з місця зупинки.
- Наступного разу достатньо `prozorro-mcp sync`, і завантажаться лише зміни.
- Лише ваша галузь: `--cpv 33` (медичні товари) або `--cpv реактиви`. Це пришвидшує роботу.
- Тендери військових частин не мають області, бо адреса прихована законом. Щоб їх додати:
  `--region "без регіону"`.

Що вже завантажено: `prozorro-mcp status`.

## Крок 4. Підключіть до ШІ-асистента

### Claude Desktop

1. Відкрийте Claude Desktop → Settings (Налаштування) → Developer → Edit Config.
2. Відкриється файл `claude_desktop_config.json`. Він лежить у `%APPDATA%\Claude\` на Windows і в
   `~/Library/Application Support/Claude/` на macOS. Впишіть:

```json
{
  "mcpServers": {
    "prozorro": {
      "command": "prozorro-mcp",
      "args": ["serve"]
    }
  }
}
```

3. Збережіть файл і повністю перезапустіть Claude Desktop. У вікні чату з'явиться значок інструментів
   з `prozorro`.

**Якщо Claude не бачить сервер**, вкажіть повний шлях до програми:
- Windows: `"command": "C:\\Users\\ВАШЕ_ІМ'Я\\.local\\bin\\prozorro-mcp.exe"`
- macOS: `"command": "/Users/ВАШЕ_ІМ'Я/.local/bin/prozorro-mcp"`

Щоб спершу спробувати на демо-даних, напишіть `"args": ["serve", "--demo"]`.

### Claude Code

```bash
claude mcp add prozorro -- prozorro-mcp serve
```

### Cursor

Відкрийте Settings → MCP → Add new global MCP server і впишіть той самий блок `mcpServers`, що й для
Claude Desktop (файл `~/.cursor/mcp.json`).

### ChatGPT і claude.ai у браузері

Вони підключаються лише до віддалених серверів через HTTPS, тому локальний сервер їм не підходить.
Розробникам: див. розділ «HTTP mode» у README.

## Крок 5. Питайте

Приклади запитань для учасника тендерів:

1. «Які відкриті тендери на лабораторні реактиви є у Львівській області? Відсортуй за дедлайном.»
2. «Покажи заплановані закупівлі лікарень Львова на найближчі два місяці, яких ще немає в тендерах.»
3. «Хто найчастіше перемагає в тендерах на борошно в нашій області і за якою ціною за кілограм?»
4. «Знайди ЄДРПОУ компанії "Київводоканал".»
5. «Хто наші основні конкуренти (ЄДРПОУ 12345678) і як часто ми їх обходимо?»
6. «Що купує замовник 05498849, у кого і скільки тендерів з одним учасником?»
7. «Покажи повну інформацію про тендер UA-2026-10-08-004705-a: хто подавався, хто переміг, документи.»
8. «Який ринок пального в області за тиждень: кількість, сума, середня кількість учасників?»
9. «Чи є червоні прапорці в закупівлях цього замовника?»
10. «Що нового з'явилося за моїми збереженими пошуками за добу?»

Червоний прапорець означає «варто придивитися», а не «порушення». Програма показує, на чому він
ґрунтується, і дає посилання на тендер.

## Без ШІ: команди в терміналі

```bash
prozorro-mcp search --cpv реактиви --region Львівська                 # відкриті тендери
prozorro-mcp search --query "борошно" --status any --since 7d         # усі за тиждень
prozorro-mcp plans --query лабораторні --budget-min 100000            # заплановані закупівлі
prozorro-mcp flags --buyer 05498849                                   # прапорці замовника
```

Таблицю можна зберегти для Excel (кирилиця відкривається правильно):

```bash
prozorro-mcp --format csv --out tenders.csv search --cpv реактиви --region Львівська
```

### Збережені пошуки й щоденна добірка

```bash
prozorro-mcp watch add "реактиви Львів" --cpv 33696 --region Львівська
prozorro-mcp watch list
prozorro-mcp digest                      # нові тендери за останню добу
prozorro-mcp watch remove "реактиви Львів"
```

**Щоранку автоматично (Windows).** Створіть у своїй домашній папці файл `prozorro-ranok.bat` з таким
вмістом:

```bat
@echo off
call prozorro-mcp sync
call prozorro-mcp --format csv --out "%USERPROFILE%\Desktop\prozorro-dobirka.csv" digest
```

Потім у PowerShell:

```powershell
schtasks /Create /SC DAILY /ST 08:00 /TN "Prozorro dobirka" /TR "%USERPROFILE%\prozorro-ranok.bat"
```

Щоранку о 8:00 на робочому столі з'являтиметься свіжий файл `prozorro-dobirka.csv`. Вимкнути:
`schtasks /Delete /TN "Prozorro dobirka" /F`.

**macOS / Linux**: `crontab -e` і додайте рядок:

```
0 8 * * * $HOME/.local/bin/prozorro-mcp sync && $HOME/.local/bin/prozorro-mcp --format csv --out $HOME/prozorro-dobirka.csv digest
```

## Часті запитання

**Наскільки свіжі дані?** Такі, як на момент останнього `prozorro-mcp sync`. Запускайте його щодня або
налаштуйте автоматичний запуск (див. вище). Дата останнього оновлення є в `prozorro-mcp status`.

**Скільки місця займає?** Тиждень великої області займає приблизно 100–200 МБ. База лежить у
`~/.prozorro-mcp/data.db` (на Windows: `C:\Users\ВАШЕ_ІМ'Я\.prozorro-mcp\data.db`).

**Чому немає результатів?** Найчастіше потрібна область або період не завантажені. Програма сама підкаже
команду, наприклад: `prozorro-mcp sync --region "Одеська область"`. Також перевірте, чи не надто вузький
фільтр.

**Чому «відкритий» тендер не показується, хоча на сайті він ще активний?** Відкритим вважається тендер,
у якого дедлайн ще не минув на момент останнього оновлення даних. Запустіть `prozorro-mcp sync`.

**Що означає прапорець?** Це правило з порогом, наприклад «ціна за одиницю на 30% вища за медіану
порівнянних закупівель». Це привід перевірити тендер, а не доказ порушення.

**Це безпечно?** Програма лише читає відкриті дані Prozorro і нічого не надсилає стороннім сервісам.
Інструменти для ШІ позначені як «тільки читання».
